# TSH Safety Core knowledge-base seed

ไฟล์ `safety-knowledge-tsh-safety-core.csv` เป็นข้อมูลหนึ่งรายการสำหรับนำเข้า `safety_knowledge` โดยใช้ Topic ใหญ่ `TSH Safety Core Activity ; SCA` และรวมรายละเอียดทั้งหมดไว้ใน `content` เดียว ปล่อยให้ระบบเดิมสร้าง `id`, `embedding`, `embedding_status` และวันเวลาที่เกี่ยวข้องเอง

แนวทางนำเข้า:

1. สำรองหรือ Export เฉพาะแถว `safety_knowledge` เดิมก่อนเปลี่ยนข้อมูล
2. ตรวจว่ามี Topic `TSH Safety Core Activity ; SCA` อยู่แล้วหรือไม่ หากมีให้ Update แถวเดิมแทนการ Insert ซ้ำ
3. Import CSV ด้วย UTF-8 และ map เฉพาะ `topic` กับ `content`
4. อย่า map ค่า `embedding` จากไฟล์นี้ และอย่ากำหนด `id` เอง
5. หลัง Import ตรวจว่า embedding worker/trigger เปลี่ยนสถานะของรายการเป็น `ready`
6. ทดลองถามคำถามหลายสำนวน เช่น “เข้าไม่ได้”, “จำรหัสไม่ได้”, “เปลี่ยนเมล”, “ไม่มีอีเมลทำอย่างไร” และตรวจว่า Chatbot ดึงเนื้อหาจาก Topic ใหญ่นี้ได้

ข้อควรระวัง:

- การเปลี่ยนอีเมลในโปรไฟล์รับอีเมลทั่วไปที่มีรูปแบบถูกต้อง แต่แบบฟอร์มสมัครบัญชีใหม่มีกติกาอีเมลของตนเอง จึงแยกเป็นคนละหัวข้อ
- ไม่ใส่รหัสผ่านจริง, SMTP secret, token, Production credential หรือข้อมูลส่วนบุคคลลงฐานความรู้
- ข้อมูลการใช้งานโมดูลเป็นคำอธิบายทั่วไป สิทธิ์จริงยังขึ้นกับ Role, Department, Unit, Safety Unit และ assignment ของผู้ใช้
- เมื่อตรรกะระบบเปลี่ยน ควรแก้แถวที่เกี่ยวข้องและสร้าง embedding ใหม่ ไม่ควรเก็บคำตอบเก่าที่ขัดกันไว้พร้อมกัน
- การรวมเนื้อหาทั้งหมดใน embedding เดียวทำให้ดูแล Topic ได้ง่าย แต่การค้นหาคำถามเฉพาะเรื่องอาจแม่นยำน้อยกว่าการแยกหลายรายการ ควรทดสอบ Retrieval จริงหลัง Import
